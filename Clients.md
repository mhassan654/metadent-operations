# Clients setup
- Uriel

## Azure resource standard names (using an example of Uriel) 
- resource group - uriel-prd-rg
- web app (backend) - uriel-be-prd-01
- web app (frontend) - uriel-fe-prd-01
- storage account - uriel-prd-01
- key vault - uriel-be-prd-01, uriel-fe-prd-01. The backend and frontend web apps require separate web apps
- database - uriel-prd-01
- database app user - uriel-prd-01
- database deploy user - uriel-prd-01


## Values to enter into the keyvault
These values should all be put into the keyvault with the following names:

- **resourceGroupName** - uriel-prd-rg
- **webAppName** - uriel-be-prd-01 (keyvault backend)
- **webAppName** - uriel-fe-prd-01 (keyvault frontend)
- **storageAccountName** - e.g. urielprd01
- **storageAccountKey**
- **storageAccountConnectionString**
- **sqlDatabaseName** - e.g. urielprd01
- **sqlAppUser** - e.g. urielprd01 (application user)
- **sqlAppPwd** - autogenerated password, 16 characters, upper/lower case alpha numeric with only special characters being dash only.
- **sqlDeployUser** e.g. deployurielprd01 (deploy user)
- **sqlDeployPwd** - autogenerated password, 16 characters, upper/lower case alpha numeric with only special characters being dash only.

## Keyvault access policies


Make sure you add the following to all keyvaults.

- Group name: DEV_ADMINS, all permissions.  this will give yourselves access 
- ADO Metadent International.  get,list on secrets only
